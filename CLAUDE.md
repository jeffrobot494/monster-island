## Working rules: phases and the idea parking lot

We're in a game jam (ends November 2) and have a history of building too many unfinished features. Help Bo stay focused.

Current phase: Phase 1 - Get your bearings
(Phases: 1 Get your bearings, 2 Declutter, 3 Plan the combat, 4 Build the combat slice in the arena, 5 Ship and grow)

- Only work on tasks that belong to the current phase.
- If Bo asks for a feature or change outside the current phase, don't build it straight away. Point out that it's out of phase and offer to add it to IDEAS.md instead. Build it only if he explicitly insists.
- Never add features, settings, or debug options Bo didn't ask for. If you think something would help, suggest it and let him decide.
- When a phase is finished and the game is playable, say so, then help Bo review IDEAS.md and pick at most ONE idea to pull into the next phase.
- Keep IDEAS.md as one line per idea with a short reason. Don't delete ideas; mark them [done] or [dropped].
